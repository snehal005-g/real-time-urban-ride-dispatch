# Real-Time Urban Ride Dispatch & Mobility Orchestration System

## Project Description

The Real-Time Urban Ride Dispatch & Mobility Orchestration System is designed to manage ride requests, drivers, users, ride allocation, and real-time mobility operations efficiently.

## Main Features

- Ride request management
- Driver management
- User management
- Ride allocation
- Real-time ride tracking
- Ride status management
- Transaction management
- Reports and analytics

## Technology Stack

- Java
- Spring Boot
- REST API
- MySQL
- Spring Data JPA
- Git & GitHub
